Dúvidas

Perguntas frequentes

Através do Open Finance Brasil, um sistema regulamentado pelo Banco Central. Você autoriza o acesso de forma segura pelo seu próprio banco, sem compartilhar senhas. O protocolo FAPI 2.0 garante que apenas os dados que você aprovar sejam acessados.
Os dados são buscados em tempo real diretamente do banco e não ficam armazenados permanentemente em nossos servidores. O token de acesso (bankJWT) fica isolado e nunca é exposto ao modelo de IA.
